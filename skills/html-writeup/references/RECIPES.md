# Document recipes

Recipes are topologies, not templates. Select the nearest one, preserve the user's real content, and change the form when the evidence shape demands it.

## Comparison

**Spine:** verdict -> decision criteria -> shared-axis comparison -> trade-offs -> recommendation.

**Forms:** short lede, one comparison table, optional alternative tabs, decision callout.

**Anchor:** the table or a two-sided visual that makes the choice legible at a glance.

**Gate:** the verdict follows evidence on shared axes, each option receives proportional evidence, and tabs contain alternatives rather than a sequential argument.

## Audit

**Spine:** overall condition -> highest-risk findings -> pattern across findings -> remediation order -> evidence appendix.

**Forms:** severity stat row, finding sections, code excerpts, risk/effort table, collapsible evidence.

**Anchor:** the ranked remediation view, not a decorative score.

**Gate:** labels or shapes carry severity without colour, every recommendation points to evidence, and visual weight follows risk.

## Research brief

**Spine:** answer -> confidence and coverage -> strongest findings -> disagreements -> implications -> source notes.

**Forms:** lede, confidence callout, finding narrative, evidence table, footnotes.

**Anchor:** the one finding or relationship that changes the reader's model.

**Gate:** the answer precedes method, findings synthesize the sources, and confidence and coverage are explicit.

## Architecture or decision record

**Spine:** decision -> forces -> current state -> proposed relationships -> alternatives -> consequences -> migration.

**Forms:** context diagram, decision table, sequence or state diagram, consequence callout.

**Anchor:** the smallest diagram that makes the boundary or flow undeniable.

**Gate:** the decision precedes implementation detail, the boundary is explicit, and every diagram edge is explained and semantically true.

## Implementation plan

**Spine:** outcome -> phases -> dependencies -> validation gates -> rollout and recovery.

**Forms:** phase timeline, dependency diagram, gate table, risk callouts, collapsible task detail.

**Anchor:** the critical path and its gates.

**Gate:** estimates are labelled, every phase has a completion criterion, and the visual form represents the real dependency structure.

## Status or incident report

**Spine:** current state -> impact -> timeline -> contributing factors -> actions and owners -> follow-up evidence.

**Forms:** status strip, impact stats, timeline, ownership table, incident flow diagram.

**Anchor:** current status for an active incident; causal timeline for a retrospective.

**Gate:** status and impact lead, every action has an owner, supplied timestamps are complete, and causal claims are distinct from chronology.

## Combining recipes

Use one recipe as the spine. Borrow a component from another recipe when it carries a specific section better, but do not combine two full spines. A research-backed comparison is still a comparison; research changes the evidence treatment, not the reader's primary job.
