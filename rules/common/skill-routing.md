# Which capsule skill to use

Load the matching skill before starting the work, not after.

| The work | Skill |
| --- | --- |
| Build, change, or fix something with a known cause | `implement` |
| Find why something fails or got slower | `diagnosing-bugs` |
| Test-first development or a regression test | `tdd` |
| Review a change | `code-review`; security or privacy: `security-review` |
| Clean up working code without changing behavior | `simplify` |
| Design modules, boundaries, or dependencies | `codebase-design` |
| Understand an unfamiliar repository | `codebase-onboarding` |
| Record or explain a technical decision | `decision-records` |
| Plan multi-step work | `planning-and-task-breakdown` |
| Commit, branch, rebase, or recover Git state | `git-workflow` |
| Write or update a pull or merge request | `pr-description` |
| Carry a pull or merge request to merge | `babysit-pr` |
| Schema or data changes | `database-migrations` |
| Make something faster, or check a speed claim | `performance`, `benchmark` |
| Audit or fix accessibility | `accessibility` |
| Decide whether to launch, or deliver a release | `production-readiness`, `ship-it` |
| Say something is done | `verification-before-completion` |
| Write for people, or for agents | `writing-for-humans`, `writing-for-agents` |
